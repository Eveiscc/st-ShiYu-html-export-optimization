# 拾玉-HTML导出

拾玉-HTML导出用于将 SillyTavern 当前已经渲染到聊天区的楼层导出为可离线打开的 HTML 文件。导出的页面会尽量保留正文排版、正则美化、主题颜色、文本背景、头像和聊天内图片，并内置收藏、目录、搜索、字体大小调节和图片保存等阅读功能。

## 主要功能

- 导出当前页面已经真实渲染的聊天楼层。
- 支持导出全部当前渲染楼层，或进入自定义勾选模式后只导出选中楼层。
- 支持临时渲染单层或指定范围到真实聊天页面，例如 `300`、`300-399`，确认图片和正则美化加载完成后再导出。
- 可内嵌聊天图片、头像、生图等资源，生成单个 HTML 文件。
- 可选择图片处理档位：
  - 不压缩：只做无损去重，保留捕获到的图片质量，速度最快。
  - 保守：WebP 0.86，适合希望轻微缩小体积。
  - 性价比：最长边 1024，WebP 0.82，适合常见 1216x832 生图。
  - 小体积：最长边 960，WebP 0.78，适合优先控制文件大小。
- 可保留当前主题颜色、文本背景、字体和酒馆视觉背景。
- 可选择段落首行空两格，便于适配不同正文美化习惯。
- 可输入收藏楼层、标签和备注；导出后仍可继续编辑。
- 可输入目录章节范围；未归类楼层会自动进入“无名之章”；导出后仍可继续编辑。
- 导出的 HTML 自带悬浮导航、目录折叠、收藏分组、页面搜索、阅读字体档位和右侧滚动进度条。
- 导出的 HTML 中点击图片可放大查看；放大后可保存图片或关闭。
- 插件面板内可搜索当前聊天记录文本，返回楼层和上下文预览，方便定位要临时渲染的范围。
- 导出过程中可取消导出任务；取消不会改变当前页面已经临时渲染出来的楼层。

## 安装

将本目录放入 SillyTavern 的第三方扩展目录：

```text
public/scripts/extensions/third-party/拾玉-HTML导出
```

重启或刷新 SillyTavern 后，在扩展面板中启用“拾玉-HTML导出”。

## 使用方式

1. 打开要导出的聊天。
2. 如果只需要当前页面已经显示的楼层，直接点击“导出当前渲染楼层”。
3. 如果要导出旧楼层，在“临时渲染楼层范围”输入单层或范围，点击“渲染选定范围到页面”。
4. 等待图片、生图和正则美化在酒馆正文区域中真实加载完成。
5. 按需要填写收藏楼层和目录章节。
6. 选择是否保留背景、是否复制完整页面 CSS、是否压缩图片。
7. 点击“导出当前渲染楼层”或进入“自定义勾选”后导出选中楼层。

## 收藏和目录格式

收藏楼层一行一条：

```text
94 | 标签 | 这里写备注
12,18,35 | 标签 | 多个楼层使用同一标签和备注
12,18,35 | 只有备注时也可以这样写
```

目录章节一行一章：

```text
20-50 | 第一章
80-90 | 第二章
```

例如当前导出楼层为 `#0-#100`，只填写 `20-50 | XXX` 和 `80-90 | YYY` 时，导出页面会自动生成：

```text
#0-#19 无名之章
#20-#50 XXX
#51-#79 无名之章
#80-#90 YYY
#91-#100 无名之章
```

## 注意事项

- 本插件以“酒馆页面上已经真实渲染出来的内容”为导出来源，不直接把完整聊天 JSON 转成 HTML。
- 如果聊天有大量楼层，建议分段临时渲染并导出，避免一次渲染过多导致 SillyTavern 卡顿。
- 生图、远程图和正则美化内容需要先在酒馆正文区域加载完成，再导出。
- 选择“不压缩”时图片质量保留最好，文件体积也最大；选择压缩档会减小体积，但导出的图片不再是压缩前的原始字节。
- “复制完整页面 CSS”可能更接近当前主题，但会更慢，也可能带入不必要样式；一般只在默认样式不准时再开启。
- “保留酒馆视觉背景”只导出背景层，不导出侧栏、输入框、设置面板等酒馆 UI。复杂动态背景或视频背景不保证完整离线复刻。
- 导出的 HTML 会包含聊天文本和内嵌图片，请按私密文件处理。
